构建原则
MANIFESTO
结构先于自动化，契约先于集成。用小 Schema 组织大系统。
先结构，后自动化
Structure before automation
先把意图、字段、边界和约束描述清楚，再让工具与 Agent 执行。
先契约，后集成
Contract before integration
API、组件、内容和工具调用都先建立可验证契约，再进入系统连接。
约束带来可靠性
Constraints enable reliability
合理约束不是限制能力，而是让 AI、API 与 UI 的执行结果可以检查、复现和维护。
