本课程把前端拆成五块可独立掌握的能力：**结构（HTML）→ 样式（CSS）→ 交互（JS）→ 组件词汇 → 布局**。

按难度分两篇：

- **基础篇**：总览 → HTML（Markdown / 视觉）→ CSS → JS → 基础组件词汇 → 排列操练（Flex / Grid）  
- **进阶篇**：常见页面骨架 → HTML 本质（DOM 树）→ 页面区块（Hero / Navbar / Sidebar）→ AI 提示词库  

先借已知概念进门，再落到浏览器真结构与复杂排列。

目标不是培养前端工程师，而是帮你获得「能看懂页面、能拆组件、能让智能助手改对前端」的表达能力。从第一节「课程导览」开始，按章节顺序推进即可。
