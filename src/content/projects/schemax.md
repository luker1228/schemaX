## 一句话定位

SchemaX 用 Schema 为未知建立可执行的结构。

## 核心能力

- 内容集合（Content Collections）由 Schema 校验，错误内容无法构建
- 设计 Token 由 Style Dictionary 从 DTCG 源自动生成
- 静态优先、零 JavaScript 优先的渲染策略（Astro Islands）
