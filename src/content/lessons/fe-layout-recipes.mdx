<StepCard num="LAY-05" label="常见问题">
  <SectionHead line1="左右位置主要由 CSS 决定" line2="aside 只是语义标签" />
  <details open style="margin-bottom: 12px;">
    <summary style="cursor: pointer; font-weight: 600; padding: 8px 0;">为什么写了 aside，有时在左边，有时在右边？</summary>
    <p style="margin: 8px 0 0; color: var(--sx-sys-color-text-soft);"><code>aside</code> 只是<strong>语义标签</strong>，本身不决定左右。真正决定它在哪一侧的是父容器的 CSS：如果用了 flex，就看 flex-direction / order；如果用了 grid，就看列怎么分配。HTML 负责表达「这里是 aside」，CSS 负责决定位置。</p>
  </details>
  <details>
    <summary style="cursor: pointer; font-weight: 600; padding: 8px 0;">那移动端为什么经常又会变成上下排列？</summary>
    <p style="margin: 8px 0 0; color: var(--sx-sys-color-text-soft);">因为在窄屏下，CSS 往往会把原来的两列布局改成单列——最常见做法是 flex-direction 从横向（row）改成纵向（column），或者重设 grid-template-columns。这样正文优先展示，aside 再往下堆叠，这叫<strong>响应式布局</strong>。</p>
  </details>
</StepCard>
