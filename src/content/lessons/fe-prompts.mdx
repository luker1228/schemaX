<StepCard num="PR-03" label="页面修改">

  <pre><code>{`请修改下面的 React 页面。

  <h3 style="margin: 16px 0 4px;">响应式修正</h3>
  <pre><code>{`请检查下面页面的移动端布局问题。

1. 避免横向滚动
2. 把多列卡片改成单列或双列
3. 缩短过长标题
4. 增加移动端按钮点击区域
5. 保持桌面布局不受影响`}</code></pre>

  <h3 style="margin: 16px 0 4px;">改文案，不改结构</h3>

<StepCard num="PR-05" label="接口对接">
  <SectionHead line1="接口对接类" line2="静态页 → 接真实数据" />

  <h3 style="margin: 8px 0 4px;">静态页改接口版</h3>
  <pre><code>{`请帮我把这个静态 React 页面改造成可以调用后端接口的版本。

接口信息：

返回数据：
{
  "list": [
    { "id": 1, "name": "张三", "role": "admin", "status": "active" }
  ]
}

要求：
1. 页面加载时请求接口
2. 增加 loading 状态
3. 请求失败时显示错误提示
4. 空数据时显示空状态
5. 不要引入复杂状态管理库`}</code></pre>

  <h3 style="margin: 16px 0 4px;">搜索 + 筛选接接口</h3>
  <pre><code>{`请把这个静态列表页改造成可搜索、可筛选的版本。
接口：
GET /api/articles?q=&category=
要求：
1. 输入框 change 时更新查询参数
2. 点击筛选标签时刷新列表
3. 请求期间显示 loading skeleton
4. 结果为空时显示 Empty State`}</code></pre>

  <h3 style="margin: 16px 0 4px;">表单提交版</h3>
  <pre><code>{`请把这个静态表单页改造成提交接口版本。

要求：
1. 点击提交时发送请求
2. 提交中禁用按钮并显示 loading
3. 成功后显示 toast
4. 失败后展示错误信息
5. 校验缺失字段后再允许提交`}</code></pre>
