  <Note tag="核心">
    选中一个 Figma 图层，右侧那块属性面板，就是它「长什么样」的全部信息。CSS 把同一块信息写成了文本：<strong>一行一个属性，冒号后面跟值</strong>，字段名几乎一模一样。
  </Note>
</StepCard>

<Takeaway
  num="CSS-F-03"
  label="总结"
  line1="Figma 视角 vs 代码视角"
  line2="字段名几乎一样"
  note="看懂对照表，再打开任何设计稿，都能把右侧面板「翻译」成一段 CSS。"
>
  <ul>
    <li>
      <strong>Figma 视角：</strong>
      右侧属性面板 = 长什么样的全部信息
    </li>
    <li>
      <strong>代码视角：</strong>
      一组「属性: 值」文本
    </li>
    <li>
      <strong>对照口诀：</strong>
      padding 内边距 · border-radius 圆角 · background 填充
    </li>
  </ul>
</Takeaway>
