<StepCard num="CMP-01" label="核心">

  <Note tag="核心">
    这页不是组件文档大全，而是给后端同学的<strong>组件词汇表</strong>。每个组件都回答三件事：1）它是什么（视觉长什么样）；2）后端怎么理解（用你熟悉的概念类比）；3）怎样描述给 AI（一句话提示词模板）。先认词，后面写提示词才不会卡壳。
  </Note>
</StepCard>

<StepCard num="CMP-03" label="Button 按钮">
  <SectionHead line1="Button 按钮" line2="像可触发动作的 RPC 入口" />
  <p>要区分主按钮（确认/提交）、次按钮（取消）、危险按钮（删除）。</p>
  <Preview>
    <div style={{ display: 'flex', gap: '12px', flexWrap: 'wrap' }}>
      <Button variant="primary">主操作</Button>
      <Button variant="secondary">次要</Button>

      <Button variant="danger">删除</Button>
    </div>
  </Preview>
  <details style="margin-top: 8px;">
    <summary style="cursor: pointer; font-weight: 600;">给 AI 的描述模板</summary>
    <p style={{ margin: '8px 0 0', color: 'var(--sx-sys-color-text-soft)' }}>请生成主按钮和次按钮两种样式，并包含默认、hover、disabled 三个状态。</p>
  </details>
</StepCard>

<StepCard num="CMP-04" label="Form 表单">

  <details style="margin-top: 8px;">

  </details>
</StepCard>

  </details>
</StepCard>

<StepCard num="CMP-06" label="Modal 弹窗">
  <SectionHead line1="Modal 弹窗" line2="像临时阻断流程的确认层" />
  <p>适合删除确认、审批确认、关键设置。弹出时背景变暗，必须先处理它才能继续。</p>
  <Preview>
    <div style={{ position: 'relative', width: '100%', maxWidth: '400px', minHeight: '180px', background: 'rgba(0,0,0,0.3)', display: 'flex', alignItems: 'center', justifyContent: 'center' }}>

          <Button variant="outline" size="sm">取消</Button>
          <Button variant="danger" size="sm">确认删除</Button>
        </div>
      </Card>
    </div>
  </Preview>
  <details style="margin-top: 8px;">
    <summary style="cursor: pointer; font-weight: 600;">给 AI 的描述模板</summary>
    <p style={{ margin: '8px 0 0', color: 'var(--sx-sys-color-text-soft)' }}>点击删除按钮后弹出一个确认 Modal，包含标题、说明文案、取消按钮和确认按钮。点击遮罩或取消按钮关闭。</p>
  </details>
</StepCard>

<StepCard num="CMP-11" label="Loading / Empty 状态">
  <SectionHead line1="Loading / Empty State" line2="页面状态机的一部分" />
  <p>它们不是装饰，而是页面状态机的一部分——<strong>AI 提示词必须明确这些状态</strong>，否则它只会给你「理想数据」的界面。</p>
  <Preview>
    <Card style={{ maxWidth: '280px', textAlign: 'center' }}>
      <div style={{ fontSize: '2rem', opacity: 0.4 }}>∅</div>
      <p style={{ margin: '8px 0 4px', fontWeight: 600 }}>暂无数据</p>
      <p style={{ margin: 0, fontSize: '0.85rem', opacity: 0.7 }}>还没有创建任何任务</p>
    </Card>
  </Preview>
  <details style="margin-top: 8px;">
    <summary style="cursor: pointer; font-weight: 600;">给 AI 的描述模板</summary>
    <p style={{ margin: '8px 0 0', color: 'var(--sx-sys-color-text-soft)' }}>表格加载时显示 Loading 骨架屏，空数据时显示 Empty State（含图标和引导文案），错误时显示错误提示条。三个状态都要。</p>
  </details>
</StepCard>
