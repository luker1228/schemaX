<StepCard num="DOM-02" label="核心">
  <SectionHead line1="HTML 文件不是页面" line2="DOM 才是" />
  <Note tag="核心">
    你写在磁盘上的 <code>.html</code> 只是<strong>文本</strong>。
    浏览器读入后会<strong>解析</strong>成内存里的一棵树：每个标签变成一个<strong>节点</strong>，嵌套变成父子关系。
    这棵树叫 <strong>DOM</strong>（Document Object Model，文档对象模型）。
    <br /><br />
    之后屏幕上画什么、JS 改什么、读屏读什么，操作的都是这棵树——不是原始字符串本身。
  </Note>
</StepCard>

  <Note tag="和 JS 的关系">
    后面讲交互时会说：JS 通过 DOM API 找节点、改文字、改 class、增删节点——
    改的是<strong>树上的对象</strong>，浏览器再根据新树重绘。
    现在只需记住：<strong>DOM 是 JS 操作页面的把手。</strong>
