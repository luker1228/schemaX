<StepCard num="FM-01" label="总图">
  <SectionHead line1="把网页想成一家商品小店" line2="三层分工，各管一件事" />
  <Note tag="核心">
    前端三剑客就是HTML，CSS还有JS。
    浏览器里的每一个页面，都可以拆成三层，就像开一家小店：  
    <strong>HTML 是骨架</strong>——店里有没有货架、收银台、购买按钮，先有这些「结构」，才知道店里有什么。  
    <strong>CSS 是装修</strong>——墙刷成黄色、灯箱字体多大、货架间距有多大，负责店里「长什么样」。  
    <strong>JS 是神经</strong>——点橱窗弹出不同商品、点购买记下选择，让店「动起来」。  
  </Note>
</StepCard>

    <p class="m-0 text-base leading-relaxed">
      {
        '神经回答的是行为：用户点了什么？当前是加载中还是失败？列表新增了一项后 DOM 怎么变？没有神经，页面只是海报；有了神经，它才是可操作的工具。'
      }
    </p>
    <p class="m-0 text-base leading-relaxed">
      {'比如你想'}
      <strong>{'点小店橱窗，弹出不同的商品'}</strong>
      {
        '——这就是神经在干活：监听到点击，换掉当前展示的商品数据，再刷新那一块界面。骨架上已有橱窗和商品位，装修决定弹层长什么样，但「点了 → 换成哪件货」是 JS。'
      }
    </p>
    <p class="m-0 text-sm leading-relaxed opacity-80">
      {'对后端同学最有用的不是「背 API」，而是三件事：'}
      <strong>{'事件'}</strong>
      {'（谁触发了）、'}
      <strong>{'状态'}</strong>
      {'（现在记着什么）、'}
      <strong>{'渲染'}</strong>
      {'（状态变了界面怎么变）。这和接口里的 request → store → response 心智很像。'}
