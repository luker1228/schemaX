<StepCard num="JS-04" label="动态添加">
  <StepSplit wide>

    <p class="m-0 text-base leading-relaxed">
      {'输入任务 → 点「添加」→ 新任务追加到列表。这里多了一步：'}

    </p>
    <ul class="m-0 pl-5 text-base leading-relaxed">
      <li>
        <strong>{'读取'}</strong>
        {'：'}
        <code>input.value.trim()</code>
      </li>
      <li>
        <strong>{'创建'}</strong>
        {'：'}
        <code>document.createElement('li')</code>
      </li>
      <li>
        <strong>{'插入'}</strong>
        {'：'}
        <code>list.appendChild(item)</code>
        {'，再清空输入框'}
      </li>
    </ul>
    <div slot="figure" class="flex flex-col gap-4">
      <DocPlayground size="md" label="动态添加" hint="输入任务 → 点添加 → 列表多一项">
        <JsDrillDemoIsland drill="add" />
      </DocPlayground>
      <Preview label="原生 JS 写法" lang="js">
        <pre><code>{`const input = document.querySelector('.task-input');
const button = document.querySelector('.add-button');
const list = document.querySelector('.task-list');

button.addEventListener('click', () => {
  const text = input.value.trim();
  if (!text) return;
  const item = document.createElement('li');
  item.textContent = text;
  list.appendChild(item);
  input.value = '';
});`}</code></pre>
      </Preview>
    </div>
  </StepSplit>
</StepCard>

<StepCard num="JS-05" label="删除事件">
  <StepSplit wide>
    <SectionHead line1="监听点击，删除与空状态" line2="条件判断 + 事件委托" />
    <p class="m-0 text-base leading-relaxed">
      {
        '删掉任务以后，如果列表空了，就显示「暂无任务」。这里练的是'
      }
      <strong>{'删除动作 + 条件判断'}</strong>
      {'。注意用了'}
      <strong>{'事件委托'}</strong>
      {
        '——不用给每个按钮单独绑监听，在父容器上绑一次就行。试着把两条都删掉，看空状态出现：'
      }
    </p>
    <ul class="m-0 pl-5 text-base leading-relaxed">
      <li>
        <strong>{'委托'}</strong>
        {'：在列表容器上听 '}
        <code>click</code>
        {'，用 '}
        <code>matches</code>
        {' 判断是不是删除按钮'}
      </li>
      <li>
        <strong>{'删除'}</strong>
        {'：找到最近的任务项，调用 '}
        <code>remove()</code>
      </li>
      <li>
        <strong>{'空状态'}</strong>
        {'：根据 '}
        <code>children.length</code>
        {' 决定是否显示「暂无任务」'}
      </li>
    </ul>
    <div slot="figure" class="flex flex-col gap-4">
      <DocPlayground size="md" label="删除与空状态" hint="删光列表后，空状态会出现">
        <JsDrillDemoIsland drill="delete" />
      </DocPlayground>
      <Preview label="原生 JS 写法" lang="js">
        <pre><code>{`const list = document.querySelector('.task-stack');
const empty = document.querySelector('.empty-state');

function syncEmptyState() {
  empty.hidden = list.children.length > 0;
}

list.addEventListener('click', (event) => {
  if (!event.target.matches('.delete-button')) return;
  event.target.closest('.task-item')?.remove();
  syncEmptyState();
});
syncEmptyState();`}</code></pre>
      </Preview>
    </div>
  </StepSplit>
