<StepCard num="BLK-01" label="核心">
  <SectionHead line1="基础组件 vs 页面区块" line2="零件小，区块大" />
  <Note tag="核心">
    基础篇认的是 <strong>Button / Card / Input</strong> 这类可嵌进任意区域的小零件。
    本课认的是 <strong>Block（区块）</strong>：通常横跨一栏或整屏，决定「这一页先看见什么」。
    和 AI 说需求时，先报区块（Hero + Navbar + 三列 Feature），再填区块里的基础组件，层次才对。
  </Note>
</StepCard>

<StepCard num="BLK-06" label="怎么用">
  <SectionHead line1="和 AI 说话时" line2="先区块，再零件" />
  <p class="m-0 text-base leading-relaxed">{'好的顺序：'}</p>
  <ol>
    <li>
      <strong>{'报骨架'}</strong>
      {'：本页有 Navbar + Hero + 三列卡片区 + Footer'}
    </li>
    <li>
      <strong>{'填区块'}</strong>
      {'：Hero 要标题 / 副文 / 两个 CTA'}
    </li>
    <li>
      <strong>{'落零件'}</strong>
      {'：CTA 用主/次 Button；卡片区用 Card 网格'}
    </li>
  </ol>
  <p class="m-0 text-base leading-relaxed">
    {'基础课的 Button / Card 在这里被'}
    <strong>{'组装'}</strong>
    {'进区块；布局课的 '}
    <code>{'header + main + footer'}</code>
    {' 则是这些区块的槽位。'}
  </p>
</StepCard>
