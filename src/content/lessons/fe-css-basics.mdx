<StepCard num="CSS-03" label="文字">
  <StepSplit wide>
    <SectionHead line1="控制文字" line2="size 管多大 · weight 管多粗" />
    <Note tag="区分">
      <code>font-size</code> 和 <code>font-weight</code> 常被混成「字变大一点」——其实管的是两件事：
      <br />
      <strong>size（字号）</strong>：字占的面积——大 / 小。
      <strong>weight（字重）</strong>：笔画的粗细——细 / 粗（如 400 常规、700 加粗）。
      可以「大而细」，也可以「小而粗」；标题往往是<strong>又大又粗</strong>，说明文常常是<strong>中等字号 + 常规字重</strong>。
    </Note>
    <p class="m-0 text-base leading-relaxed">
      <strong>{'只改 size：'}</strong>
      {'同一字重，字号从 16 → 32，占位变大，更抢视线。'}
    </p>
    <p class="m-0 text-base leading-relaxed">
      <strong>{'只改 weight：'}</strong>
      {'同一字号，从 400 → 700，笔画变粗，更「压得住」，但不一定更大。'}
    </p>
    <p class="m-0 text-base leading-relaxed">
      <strong>{'一起用：'}</strong>
      {'标题常用「较大 size + 较重 weight」；说明文用「较小 size + 常规 weight」。'}
    </p>

<StepCard num="CSS-04" label="颜色">
  <StepSplit wide>
    <SectionHead line1="控制颜色" line2="以前景色 · 背景色 · 边框色拆开看" />
    <Note tag="四个槽位">
      拿一个 <strong>button</strong> 举例：你看到的「按钮颜色」常拆成多块（CSS 各管一属性）：
      <br />
      <strong>前景色</strong> <code>color</code>——字 / 图标的颜色。
      <strong>背景色</strong> <code>background</code>（或 <code>background-color</code>）——按钮底的颜色。
      <strong>边框色</strong> <code>border-color</code>（常和 <code>border</code> 一起写）——描边的颜色。
      <strong>阴影色</strong>——写在 <code>box-shadow</code> 里（偏移 + 模糊 + <strong>颜色</strong>），不是单独的
      <code>shadow-color</code> 属性；本站硬阴影多是黑影，也可以是半透明灰、强调色。
      四者可独立组合：结构仍是同一个 <code>{'<button>'}</code>。
    </Note>
    <p class="m-0 text-base leading-relaxed">

        {'只改前景色 '}

      </strong>
      {'底和边不变，字变色。'}

<StepCard num="CSS-05" label="留白">
  <StepSplit wide>
    <SectionHead line1="控制留白" line2="padding 怎么拆" />
    <Note tag="是什么">
      <code>padding</code> 是<strong>内容到边框之间</strong>的内边距（盒子「肚子里」的空白）。
      小 = 挤，大 = 松。它不是元素之间的间距——元素与元素之间多用
      <code>margin</code> 或 flex 的 <code>gap</code>。
    </Note>
    <p class="m-0 text-base leading-relaxed">
      <strong>{'按方向拆成四边'}</strong>
      {'（各写各的，或用简写一次写完）：'}

        <tr>
          <td class="doc-props__name">padding-right</td>
