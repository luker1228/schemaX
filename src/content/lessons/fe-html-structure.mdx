<StepCard num="HTML-01" label="核心">
  <SectionHead line1="Html 可以看做 Markdown" line2="同一类结构，两套写法" />
  <Note tag="核心">
    <strong>Html 可以看做 Markdown</strong>——都是在描述「有什么结构」。
    上一节说过：小店里有没有货架、标题、购买按钮，由 <strong>HTML 骨架</strong>决定。
    Markdown 用 <code>#</code> 表示标题，HTML 用 <code>&lt;h1&gt;</code>；Markdown 用
    <code>-</code> 表示列表，HTML 用 <code>&lt;ul&gt;&lt;li&gt;</code>。概念一样，写法不同。
    后端同学不必背全标签表，但要形成稳定判断：<strong>先想区块，再选语义标签</strong>。
  </Note>
</StepCard>
