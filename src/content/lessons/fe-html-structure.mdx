<StepCard num="HTML-02" label="示例">
  <StepSplit layout="stack">
    <SectionHead line1="容器标签" line2="就是视觉里的「框」" />
    <Note tag="容器">
      第 1 节说的「框」，在 HTML 里就是<strong>容器标签</strong>：<code>{'<div>'}</code>、<code>{'<section>'}</code>、<code>{'<header>'}</code>。它们在结构上做同一件事：框住一组内容，可以再套一层。外观靠 CSS、不靠标签名；名字的差别主要是语义（如 header ≈ 页头、section ≈ 分区），方便读代码和无障碍。
      <br />
      那 <code>{'<div>'}</code> 和 <code>{'<header>'}</code> 差在哪？<strong>渲染出来都是框，长得一模一样</strong>——差别只在<strong>语义</strong>。<code>{'<div>'}</code> 是「说不清这块算什么」的通用框；而 <code>{'<header>'}</code>（页头）、<code>{'<nav>'}</code>（导航）、<code>{'<main>'}</code>（主内容）、<code>{'<article>'}</code>（一篇独立内容）、<code>{'<footer>'}</code>（页脚）这些<strong>语义标签</strong>，等于给框贴了角色名牌，让浏览器、屏幕阅读器、搜索引擎都认得出每块是什么。所以初学全用 <code>{'<div>'}</code> 没问题——就像图层面板里全叫 Frame 1、Frame 2，结构照样搭得出来；进阶再把对应位置换成语义标签，代码对人好读、对机器也友好。想知道每个 <code>{'<div>'}</code> 该换成哪个语义标签？见{' '}
      <a href="https://www.freecodecamp.org/chinese/news/semantic-html-alternatives-to-using-divs/" target="_blank" rel="noopener noreferrer">这篇《用语义标签替代 div》讲得很全 ↗</a>。
    </Note>

<StepCard num="HTML-03" label="标记">
  <StepSplit layout="stack">
    <SectionHead line1="什么是标记语言" line2="先从 Markdown 说起" />
    <Note tag="核心">
      上一节你已经见过 <code>{'<div>'}</code>、<code>{'<section>'}</code> 这些标签——它们就是用尖括号包住一个名字。这种<strong>给内容贴标签</strong>的写法从哪来？答案就藏在你早就会的一种语言里：<strong>Markdown</strong>。<code>#</code> 标了「这是标题」、<code>-</code> 标了「这是列表项」、<code>**</code> 标了「这是重点」——给内容贴上<strong>角色</strong>，机器才知道怎么呈现它。
      <br />
      这套「用符号标出角色」的做法，就叫<strong>标记语言</strong>。<strong>HTML 是另一种标记语言</strong>：把符号换成带角括号的标签，描述的是同一套结构——<code>&lt;h1&gt;</code> 对应 <code>#</code>、<code>&lt;li&gt;</code> 对应 <code>-</code>、<code>&lt;strong&gt;</code> 对应 <code>**</code>。
    </Note>
    <p class="m-0 text-base leading-relaxed">
      {'同一张小店，Markdown 和 HTML 各写一遍，结构一模一样：'}
    </p>
    <div slot="figure" class="flex flex-col gap-4">
      <CodeCompare
        from="MARKDOWN.MD"
